# 项目里程碑

## M1：首条数学工程闭环

交付一条可演示的窄链路：文本/DOCX/图片中的一种输入 → 数学提取 → 知识单元 → 可执行模型 → 思维链 → 用户召唤的多个 Agent → Python 执行 → 可视化 → 验证 → 工程包导出。

实现顺序由能最快交付可运行闭环的任务卡决定。只有这条链路实际需要的公共契约才进入工作范围。

## M2：扩大数学能力

扩展输入类型、题型、模型、Agent 协作、验证和工程包的覆盖面，并将经过真实使用验证的内部结构提炼为公共契约。

## M3：视频转工程

支持用户有权访问的视频、时间溯源和知识工程转换。

## 后续

扩展更多资料格式、学科插件、本地运行时、外部工具和真人协作。
