# 项目里程碑

## M0：治理底座

- 建立单仓库边界、长期事实文档、ADR/RFC 流程、GitHub 模板、CI、仓库规则和六个 Codex skills。

## M1：公共契约

- 定义并测试公共契约清单中的 11 个类型。
- 此阶段不追求完整 UI；交付目标是明确所有权、兼容性和可独立开发的稳定接口。

## M2：数学垂直切片

- 从文本/DOCX/图片解析开始，保留不可变原件和溯源。
- 支持几何、空间数学、微积分、微分方程和数学建模。
- 支持思维链、长期多 Agent 控制、Python 执行、可视化、验证、回滚和开放工程包导出。

## M3：视频转工程

- 支持用户有权访问的视频：捕获回退链路、自适应抽帧、字幕对齐、时间溯源、知识单元、
  项目候选和角色可配置的 Agent 知识增强。

## M4 及以后

- PDF、Excel、音频和电子教材。
- 物理、化学、生物和地理插件。
- 本地/私有运行时、外部科学工具，以及后期多真人协作。

GitHub Project 是唯一实时任务看板；本文件只记录顺序和里程碑退出条件。
