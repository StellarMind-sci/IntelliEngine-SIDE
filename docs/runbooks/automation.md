# 自动化运行手册

自动化默认只报告问题或创建 Issue；不自动合并大范围代码修改。

## 每日契约与安全检查

- 在隔离 worktree 中运行 CI。
- 报告失败的契约、权限、沙箱、溯源和开放工程包检查。
- 每一种独立失败最多创建或更新一个边界明确的 Issue。

## 每周文档漂移检查

- 将当前公共接口和测试与架构文档、ADR、最近的 AGENTS.md 比较。
- 只提出长期事实的修正；不要创建第二个任务状态看板。

## 里程碑文档压缩

- 找出被替代草案、重复说明、过时路由和术语漂移。
- 保留已接受 ADR 的历史；用新 ADR 替代旧决定，而不是重写历史。

先手动测试自动化提示，再安排周期任务。使用隔离 worktree 和最小权限。
