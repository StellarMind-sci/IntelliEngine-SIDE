# Codex 开发指导

## 普通任务启动格式

```text
项目目标：
当前产品阶段：
本任务要增加的用户能力：
允许修改路径：
非目标：
验收条件：
测试命令：
当前已知问题：
```

按“实现 A + … + 实现 N → 最终审核与测试 → 合并 → 演示”推进。中央会话可自行创建任务卡、分支、worktree、提交、PR、合并和演示交付。

## 高风险任务额外格式

```text
风险提示：
权限边界：
兼容性/迁移：
回滚方案：
安全测试：
人工审查条件：
```

高风险变更测试后交付人工审查；不得假定人工审查已完成。

## 最小重载

仅在上下文压缩、会话交接、长时间暂停、重大架构变化或高风险审查前读取产品、直接相关架构、当前任务卡和实时 Git 状态。连续普通开发不做全仓重载。
