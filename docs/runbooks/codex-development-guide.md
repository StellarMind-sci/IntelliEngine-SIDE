# Codex 开发指导

## 普通任务启动格式

```text
项目目标：
当前产品阶段：
本任务要增加的用户能力：
允许修改路径：
非目标：
验收条件：
测试命令：
当前已知问题：
```

任务卡或交付说明中的“验收”必须包含：用户能力、验收入口、前置条件、操作步骤、预期结果、异常场景、视觉证据、自动化证据、已知限制与回滚。无界面任务提供可执行 CLI/API/fixture/日志/结构化输出及输入/输出示例。界面任务另需可复制启动命令、固定演示数据、正常/阻断或错误/空状态三场景，以及截图或录屏（不能提供时写明替代验证方式）。

按“实现 A + … + 实现 N → 最终审核与测试 → 合并 → 演示”推进。中央会话可自行创建任务卡、分支、worktree、提交、PR、合并和演示交付。

## 高风险任务额外格式

```text
风险提示：
权限边界：
兼容性/迁移：
回滚方案：
安全测试：
人工审查条件：
```

高风险变更测试后交付人工审查；不得假定人工审查已完成。

## 最小重载

仅在上下文压缩、会话交接、长时间暂停、重大架构变化或高风险审查前读取产品、直接相关架构、当前任务卡和实时 Git 状态。连续普通开发不做全仓重载。
