# ADR-0002：仓库是长期记忆

- 状态：已接受
- 日期：2026-07-12
- 替代的旧 ADR：无

## 背景

长期开发会跨越多个 Codex 任务和上下文窗口。聊天记录无法成为产品意图、架构、
行为和验证的唯一记录。

## 决定

产品和架构事实存放于当前文档，决定存放于 ADR，行为存放于代码和测试，
任务状态存放于 GitHub Issues/Projects。Codex 对话和 RFC 草案均为临时资料。

## 结果

每个完成任务必须留下可合并产物或明确阻塞结论，并附带测试证据和接口影响。
禁止手动维护重复任务看板。

## 验证

Issue 和 PR 模板要求填写验证、依赖、接口影响和回滚说明。
