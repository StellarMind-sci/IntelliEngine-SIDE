# ADR-0004：控制工程是智能行为的元控制层

- 状态：已接受
- 日期：2026-07-12
- 替代的旧 ADR：无

## 背景

解析、Agents、动态建模、思维链同步、资源使用、验证和回滚都需要可配置自主性。
若每个功能各自维护设置，规则会冲突且难以解释。

## 决定

所有智能副作用通过一个可版本化控制平面；策略可在全局、项目、团队、Agent、
节点和任务范围逐层生效。信任与权限分离，策略支持预演、冲突解释、审计、验证、
提交和回滚。

## 结果

多种协作和自主模式可以作为参数共存。平台安全上限不可被覆盖，
动态模型不能绕过能力限制。

## 验证

M1 必须先为 ControlPolicy 和 ChangeSet 定义契约测试，再实现使用方。
