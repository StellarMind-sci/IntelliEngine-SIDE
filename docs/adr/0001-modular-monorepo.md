# ADR-0001：采用模块化单仓库

- 状态：已接受
- 日期：2026-07-12
- 替代的旧 ADR：无

## 背景

第一条产品链路横跨 UI、语义契约、Agent 控制、解析、溯源和 Python 运行时。
在这些边界尚未稳定前，它们需要同步演进。

## 决定

应用、packages、services 和第一方插件保留在同一仓库，并明确模块所有权。
只有当组件的公共契约和独立发布周期稳定后，才考虑拆到独立仓库。

## 结果

跨模块修改可原子提交，CI 可集中验证契约。并行任务仍需使用分支/worktree，
且不得同时修改同一不稳定契约。

## 验证

治理检查脚本会检查必要模块目录和规则文件。
