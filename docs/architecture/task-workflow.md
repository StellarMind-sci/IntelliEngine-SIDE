# Codex 任务流程

1. 选择一个符合任务契约模板的 GitHub Issue。
2. 为该 Issue 启动一个 Codex 任务，并使用一个分支/worktree。
3. 阅读根目录和最近的 AGENTS.md、Issue、受影响契约和直接相关的 ADR。
4. 修改前确认范围和测试。
5. 实现最小但完整的变更，运行规定检查。
6. 在 Pull Request 中记录接口变化、测试证据、风险和回滚方式。
7. 集成前安排一个独立审查任务。
8. 公共契约先合并，再并行实现使用方；跨模块联调由独立集成任务处理。

聊天是临时的；代码、测试、契约、已接受 ADR 和当前架构文档才是长期事实。
