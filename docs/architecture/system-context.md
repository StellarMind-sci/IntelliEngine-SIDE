# 系统架构概览

## 长期层次

1. **认知内核**：通用原语，以及学科原生类型和项目级动态类型。
2. **知识与思维链**：可复用知识单元与可执行的控制/逻辑图。
3. **控制平面**：处理 Agent、解析、建模、同步、资源、验证、提交和回滚的策略。
4. **Agent 运行时**：与模型提供商无关的长期身份和记忆。
5. **执行平面**：首期为隔离 Python/Jupyter，后续扩展其他及本地运行时。
6. **体验层**：IDE 外壳、认知画布、上下文视图和事件触发的辅助。

## 数据流

不可变原件 → 解析服务 → 溯源记录 → Cognitive IR/领域模型 → 知识/思维链 → ChangeSet →
验证与运行时 → 已提交产物

任何会产生副作用的动作都必须经过控制平面。信任与权限是两件不同的事。
动态类型默认允许创建，但不能绕过能力和权限检查。

## 部署方向

第一阶段采用 Web 优先、云端默认。存储、模型和运行时均使用可替换接口，
以便未来增加本地执行和私有部署，而无需改变开放工程包格式。
