# 第一条垂直切片的用户流程

1. 用户导入文本、DOCX 或包含几何、微积分、微分方程、数学建模题目的照片。
2. 原件以不可变形式保存；提取出的文字、公式、图形和结构保留对象级溯源。
3. 有权限的 Agent 处理允许范围内的歧义；其余选择展示给用户确认。
4. 系统生成 Cognitive IR 节点、知识单元、数学领域模型和思维链。
5. 用户召唤一个或多个长期 Agent，并通过控制图配置其角色。
6. 系统提出 Python/SymPy/NumPy/SciPy 代码、测试和交互式可视化建议。
7. 修改思维链会生成可审查的 ChangeSet；代码执行会更新其逻辑投影图。
8. 用户可以分支、比较、验证、回滚，并导出开放工程包。
