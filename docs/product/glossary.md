# 术语表

- **Cognitive IR（认知中间表示）**：跨学科共用的实体、变量、关系、约束、状态、过程、
  目标、证据、假设、动作和实验等原语。
- **领域模型**：在 Cognitive IR 上扩展的学科原生类型与规则。
- **动态模型**：用户或获授权 Agent 在项目中运行时创建的模型或类型。
- **知识单元（KnowledgeUnit）**：含概念边界、表示、依赖、示例、可执行行为、验证、溯源
  和能力证据的可复用对象。
- **思维链（Thoughtflow）**：可编辑、可执行的意图、控制、代码结构、依赖、实验、决策和
  验证图。
- **Agent**：长期存在的 AI 个体；身份、记忆、权限、模型路由、成长和关系不绑定于单一模型。
- **控制工程（Control Engineering）**：管理触发、执行者、信任、权限、自主性、验证、
  资源、提交和回滚的版本化元控制层。
- **ChangeSet**：跨代码、模型、思维链、配置、测试和影响信息的原子化、可审查变更提案。
- **溯源（Provenance）**：对象级别追踪原始资料及其转换历史的能力。
- **开放工程包（Open Project Package）**：可移植工程格式；默认不含密钥和用户私有全局
  Agent 记忆，除非用户显式加密并导出。
