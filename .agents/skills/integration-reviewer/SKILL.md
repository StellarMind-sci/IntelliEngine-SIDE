# 集成审查器

1. 确认已接受契约、模块版本、生产者/使用方所有权和预期端到端流程。
2. 确认每个模块已通过自身检查。
3. 跨边界追踪数据、身份、溯源、权限、错误、重试和回滚。
4. 发现重复领域逻辑、私有契约导入、不兼容默认值、隐藏云端状态和绕过控制平面的行为。
5. 运行契约与集成测试，再运行最小代表性端到端场景。
6. 集成修复必须保持窄范围；将模块缺陷退回其所有者 Issue，不要用永久适配器掩盖它。
7. 输出按严重程度排序的问题、验证证据、发布阻塞项和后续 Issue 契约。
