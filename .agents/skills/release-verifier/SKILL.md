# 发布验证器

1. 确认候选 commit/tag、上一已知正常版本、包含的 Issues、环境和批准负责人。
2. 确认同一候选已通过 CI、契约、集成、安全、开放工程包兼容和构建检查。
3. 审查公共接口变化、数据迁移、兼容窗口、密钥、模型/运行时配置和第三方依赖。
4. 确认高风险行为有功能开关、可观测性和可逆性。
5. 运行 staging 冒烟测试和回滚手册；绝不在生产环境执行破坏性回滚演练。
6. 分类发布阻塞项、已接受风险和发布后监控。
7. 输出完整检查表，并明确给出 GO、NO-GO 或 GO WITH CONDITIONS，以及每项条件的证据。

除非用户显式授权，否则不要部署或创建发布标签。
