# 契约审查器

1. 阅读契约所有者、已接受 ADR/RFC、使用方、序列化格式和契约测试。
2. 检查名称和语义是否明确，并在需要时保持跨学科中立。
3. 检查版本、前后兼容、默认值、未知字段/类型、迁移和回滚。
4. 检查对象级溯源、信任与权限分离、能力边界、审计，以及密钥/私有记忆排除。
5. 检查失败行为、重试、幂等性和确定性校验。
6. 确认测试覆盖有效样例、无效输入、兼容性、往返序列化和使用方场景。
7. 按严重等级和精确位置报告可执行问题；若无问题，说明剩余风险和缺失证据。

除非用户另行要求修复，否则只审查。
