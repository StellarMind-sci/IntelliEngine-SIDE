# 模块实现器

1. 阅读 Issue、根目录和最近的 AGENTS.md、受影响契约和直接关联 ADR/RFC。
2. 确认只有一个主要模块、一个 PR 结果和最多一项公共契约变化；否则停止并请求拆分。
3. 修改前阅读当前代码与测试，保护无关用户改动。
4. 只在允许路径中实现最小完整方案。
5. 添加单元测试及受影响的契约、集成和安全测试；必要时保留溯源、显式能力、幂等性和回滚。
6. 运行指定命令并记录准确结果。
7. 只有长期事实改变时才更新架构文档或 ADR。
8. 输出可直接用于 PR 的摘要：结果、文件/行为、接口影响、验证、剩余风险、回滚和后续 Issues。

不要扩大范围、擅自决定产品策略、发布或合并。
